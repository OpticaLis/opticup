איך לקרוא תור ביומן

Dual-color system

צבע פנימי (רקע) = סוג-מפגש. ירוק=מבוגרים, כחול=ילדים, סגול=מולטיפוקל, צהוב=עדשות-מגע. ה-tenant יכול לשנות את הצבעים בהגדרות-סוגי-מפגשים.

צבע חיצוני (מסגרת) = סטטוס. 7 סטטוסי-מערכת (קבועים) + סטטוסים-משלך-להוסיף (כמו "VIP" כאן). מסגרת-מקווקוות = ממתין-לאישור. מסגרת-עבה = VIP.

Interactions

לחיצה על slot ריק: דיאלוג מהיר ליצירת תור (תאריך/שעה/אופטומטריסט מלאים מראש).

לחיצה על תור: פאנל-צד עם פרטי-תור + 5 פעולות (אישור-הגעה / שינוי / ביטול / כרטיס-לקוח / ➕ הזמנה).

גרירה (drag): הזזת-תור לזמן אחר → דיאלוג-אישור + checkbox "שלח הודעה ללקוח".

קליק-ימני באזור-זמן: "חסם זמן זה" עם סיבה (פגישת-צוות / חופשה / אחר).
