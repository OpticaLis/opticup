הכללים מאחורי הסקיצה

  • גרעין: פר-תת-הזמנה. תת-הזמנה אחת = טופס אחד. עד 8 טפסים מודפסים פר-הזמנה.
  • בלוקי-מוצר: מוצגים רק אלה שנמצאים בתת-ההזמנה. מסגרת+עדשות = שני בלוקים. רק-מסגרת = בלוק אחד. וכו'.
  • שורת-סטטוס "Sent / Ordered / Shelf": מודפסת רק על בלוק-עדשות (וריאנטים 1, 3) ועל בלוק-עדשות-מגע (וריאנט 4). מסגרת ואביזרים — אין סטטוס-מעבדה. הסימון ידני.
  • בלוק-מרשם: מודפס רק כשיש עדשות (משקפיים או מגע) ויש מרשם מחובר להזמנה. מסגרת-בלבד / אביזרים = אין מרשם.
  • סוג-מרשם (Multifocal / Reading / Distance / Office): ה-checkbox המתאים נסמן אוטומטית לפי הסוג שמחובר. השאר ריקים.
  • ברקודים: 4 מיקומים בעמוד (פינות + מרכז) — כולם אותו מזהה (1-9362-A). חיתוך/קיפול לא ישבש סריקה.
  • חתימות: Optometrist / Employee / Optician — שדות לא-רלוונטיים מסומנים מפורשות (למשל אביזרים = "לא רלוונטי" בכל שלושה).
  • טופס פנימי בלבד — אין תלוש-לקוח. קבלה/חשבונית מודפסות ע"י הקופה (כיום ידנית, בעתיד דרך API לקופה חיצונית).
